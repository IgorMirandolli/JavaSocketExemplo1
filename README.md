JavaSocketExemplo1
Este repositório contém um exemplo prático de comunicação via rede utilizando Sockets em Java. O projeto demonstra a implementação básica de uma arquitetura Cliente-Servidor para troca de mensagens simples.

🚀 Estrutura do Projeto
O projeto é dividido em duas partes principais:

Servidor: Fica em "escuta" em uma porta específica aguardando conexões.

Cliente: Conecta-se ao IP e porta do servidor para enviar ou receber dados.

🛠️ Tecnologias Utilizadas
Linguagem: Java

API: java.net.Socket e java.net.ServerSocket

Conceitos: TCP/IP, Fluxos de entrada/saída (I/O) e Gerenciamento de portas.
